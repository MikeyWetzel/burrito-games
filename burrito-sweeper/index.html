How to play

  • Double tap a tile to reveal. First reveal is always safe.
  • Single tap places a marker. By default taps cycle: empty → burrito → avocado → nacho → empty.
  • Use the marker picker below to place a specific type with each tap (tap the selected chip again to return to cycle mode). Only the burrito counts toward the counter and chording; avocado & nacho are maybe-notes.
  • Drag to pan · pinch (or wheel) to zoom · Fit board recenters.
  • Double tap a number with the right burrito count to chord. Boards are logic-solvable — no forced guesses.
